# Foodzilla - UX & Prototyping

## Task
Medium - UX & Prototyping

## Project
Foodzilla is a mobile food-ordering app prototype designed in Figma.

## Approach
I designed a complete mobile user flow including onboarding, home/dashboard, menu, food details, cart/order summary, and profile/settings.

## Tools Used
- Figma
- Figma Make

## Figma Prototype
